Describe an image and RAGNA Studio generates it. Open **Images** in the sidebar to get the **Text to Image** page. The form sits at the top. Your generated images fill the gallery below it.

<Aside type="note">
  Self-hosted installs need a key for at least one image provider. See [Optional
  providers](/self-hosting/optional-providers).
</Aside>

## Generate an image

1. Describe the image in the prompt field (up to 5,000 characters).
2. Pick a model.
3. Set the **Aspect ratio**: `1:1`, `4:3` or `16:9`.
4. Set the **Resolution**: `1K` or `2K`.
5. Set the **Number of images**: 1 to 4.
6. Choose **Generate image**.

Your settings are remembered for next time. The long edge of a `2K` image is 1920 pixels.

## Models and providers

The model list shows every image model your installation offers. RAGNA Studio supports three providers:

- Black Forest Labs (FLUX)
- Google Vertex (Imagen)
- OpenAI

Which models you see depends on what the person running your installation has set up.

## Advanced options

Open **Advanced options** for more control. Each option works only where the selected model supports it. Otherwise the field is disabled, and a tooltip names the model that lacks it.

- **Negative prompt:** describe what to avoid.
- **Seed:** a number that makes results repeatable.
- **Use reference images:** guide the result with up to four images. Choose **From gallery** to pick one of your completed images, or **Upload** to add a new one. The counter shows how many you selected. The maximum depends on the model.

The settings are cleared after each run. To repeat a run, open an image and choose **Reuse settings**. It copies the model, ratio, resolution, seed and negative prompt into the form. Fields the model does not support are dropped.

## Label as AI generated

Turn on **Label as AI generated** to burn a small badge into the image. See [AI labeling](/media/ai-labeling).

## Background execution

Generation runs in the background. New images appear in the gallery at once as pending tiles. You can leave the page. When the batch finishes, a notification arrives in the bell: **Images ready** or **Image generation failed**.

If a batch fails, every image in it shows **Image generation failed.** Try again with a different prompt or model.

## Work with a result

Click an image to open **Generated image**. You can:

- see the prompt, model and settings,
- **Copy prompt**,
- **Download** the image,
- **Delete** it. This cannot be undone. A file that is still used elsewhere stays. See [Media library](/media/library).

## Images in chat

Turn on the **Image Generation** tool in an agent to let it create images in a chat. See [Agent tools](/agents/tools). The chat tool does not offer the AI label.
