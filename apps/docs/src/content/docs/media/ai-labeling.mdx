Generated images and videos can carry a small visible badge. The badge is a thin ring with the letters "AI" inside. It sits in the bottom-right corner and is meant to be subtle. It helps where AI-generated content must be disclosed to an audience.

## Turn it on

Both generation forms have a switch named **Label as AI generated**. It is off by default.

1. Open **Images** or **Videos**.
2. Turn on **Label as AI generated**.
3. Generate as usual.

RAGNA Studio remembers the setting for the next time. The badge is burned into the file that RAGNA Studio stores. Downloads carry it too.

## What it applies to

- Images and videos created on the **Images** and **Videos** pages.
- Videos enhanced from a draft with **Enhance**. They inherit the setting of the draft.

It does not apply to:

- images or videos an agent creates in a chat,
- uploaded files,
- existing files. The badge cannot be added later.

## Check what was applied

Open an image or video. The **AI label** row shows **Applied** when the badge is on the stored file. If adding the badge failed, the image or video is kept without it, and the row is empty. The render is never lost because of the label.

## Provider marking

The badge is separate from the marking that model providers add on their side. RAGNA Studio never turns provider marking off. Provider marking can disappear when a file is edited or re-exported elsewhere. The visible badge survives such steps.

<Aside type="note">
  The badge helps disclose AI content. It does not replace a legal review. Check which rules apply
  to the intended use.
</Aside>
