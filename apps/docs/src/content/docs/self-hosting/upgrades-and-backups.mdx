## Upgrades

Run the installer with `--upgrade`, from the folder that contains `ragna-studio`:

```bash
curl -fsSL https://get.ragna.io | sh -s -- --upgrade
```

It moves `RAGNA_VERSION` in `.env` to the latest release, downloads that release's compose files, pulls the images and restarts. The rest of `.env` stays as it is.

Migrations run automatically and only go forward.

### Manual setup

If you [installed by hand](/self-hosting/install-options/docker-compose), do the same steps yourself:

1. Set `RAGNA_VERSION` in `.env` to the new release.
2. Download that release's files, as in [step 1](/self-hosting/install-options/docker-compose#step-1-download-the-release-files).
3. Run the `up -d --wait` command from [step 3](/self-hosting/install-options/docker-compose#step-3-start-everything). It pulls the new images and restarts.

Or switch to the installer. It recognizes your folder because `.env` has `RAGNA_VERSION`.

## Backups

The state you own is Postgres, Redis and both buckets. Backups are up to you.

<Aside type="caution" title="Keep your secrets with your backups">
  Encrypted values in the database, such as stored OAuth tokens, are only readable with the same `BETTER_AUTH_SECRET` and `ENCRYPTION_PASSWORD`. Store both safely, next to your backups.
</Aside>
