These docs name the product RAGNA Studio throughout. The open-source edition is licensed under [AGPL-3.0](https://github.com/ragna-ai/ragna-studio/blob/main/LICENSE) and ships with the RAGNA Studio brand.

Organizations that want to offer RAGNA Studio under their own name and logo, for example to their own customers, can do so under a commercial license. The same license covers use without the AGPL obligations, such as in a closed-source product.

For white-labeling and commercial licensing, contact [license@ragna.io](mailto:license@ragna.io).
