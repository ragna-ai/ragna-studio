Both options run the same release images with the same compose files. They differ in who writes the setup.

| Option                                                                       | Best for                                                                                                                        |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| [One-line setup](/self-hosting/install-options/one-line-setup)               | Most installs. One command checks the system, writes `.env` with generated secrets, asks for the settings and starts the stack. |
| [Install using Docker Compose](/self-hosting/install-options/docker-compose) | Full control. The operator downloads the compose files and writes `.env` by hand.                                               |

Switching later is possible. A manual setup with `RAGNA_VERSION` in `.env` works with the installer's `--upgrade`.
