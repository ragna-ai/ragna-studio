Both options run the same release images with the same compose files. They differ in who writes the setup.

| Option                                                                       | Best for                                                                                                                          |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| [One-line setup](/self-hosting/install-options/one-line-setup)               | Most installs. One command checks your system, writes `.env` with generated secrets, asks for your settings and starts the stack. |
| [Install using Docker Compose](/self-hosting/install-options/docker-compose) | Full control. You download the compose files and write `.env` yourself.                                                           |

You can switch later. A manual setup with `RAGNA_VERSION` in `.env` works with the installer's `--upgrade`.
