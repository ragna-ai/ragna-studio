The team node lets one agent lead several others. The lead gets a task, splits it up, hands the parts to specialists and writes the final answer. Use it when one agent is not enough, for example research by one agent and writing by another.

## Set up a team

1. Add a **Team** node and select it.
2. In the **Lead** section, choose the lead agent. It is required.
3. Write the **Prompt**. The lead gets this task and hands parts of it to the members. It can use `{{input}}` for the output of the previous node.
4. In the **Members** section, click **Add member** for each specialist. The heading shows the count, for example **Members (2/5)**.
5. For each member, pick an agent. Fill in the **Role**, such as "researches background facts".

A team has one to five members. The last member cannot be removed, because a team needs at least one. Each member needs an agent. The **Role** tells the lead when to hand work to that member. If it is empty, the lead only sees the agent's name.

## Read the team on the canvas

The team node lists the **Lead** first, then each member with its agent name and role. An agent that is not picked yet shows "No agent yet". An agent that was deleted shows "Deleted agent". A lead or member with a problem is shown in red. In the side panel, each member card is titled with the agent name.

All agents must belong to the same workspace as the workflow. The same agent can be a member twice with different roles.

## How delegation works

The mode is delegate. The lead gets a briefing with the list of members and their roles. It then works in a loop:

1. The lead breaks the task into subtasks.
2. It sends each subtask to the member whose role fits.
3. It reads the reports and can send work back to refine it.
4. When it is satisfied, it writes the final answer itself.

The output of the team node is that final answer.

When the lead sends independent subtasks in the same step, the members work at the same time. How much work runs in parallel depends on the lead's choices.

## Lead and member settings

- **Lead:** the lead keeps its own model, instructions, knowledge and tools. It can use them next to delegating.
- **Members:** each member runs like it does in chat, with its own model, tools and settings.

## Limits

A lead takes at most 12 steps. A member takes at most 15 steps per delegated task. A very large team with long tasks can still take a while.

## See what happened

Open the run and select the team node. **Agent trace** shows each step of the lead, every delegation and the member's tool calls, with duration and tokens. See [Runs and traces](/workflows/runs).
