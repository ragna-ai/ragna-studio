Chat is where you work with an agent. Answers stream in as the agent writes them. Every chat is saved in your workspace.

## Start a chat

- Open **Chat** in the sidebar. You talk to the workspace's [default agent](/agents).
- Or choose **Chat** next to an agent in the **AI agents** list.
- Or pick an agent tile on the home page.

While a chat is open, the top bar shows the agent's name. Use the plus button there to start another chat with the same agent.

Type in the box ("How can I help you?") and send. The answer streams in. While the agent is working, the send button becomes a stop button. Use it to cancel the answer.

When the agent uses [tools](/agents/tools), each use appears as a step in the answer.

<Aside type="caution">
  AI generated. Responses may be incorrect. Verify important information.
</Aside>

## Attach files

Choose the attach button (**Attach files**), or drop files onto the chat. You can attach images and documents.

| Kind      | Types                               |
| --------- | ----------------------------------- |
| Images    | PNG, JPG, JPEG, WEBP                |
| Documents | PDF, DOCX, PPTX, XLSX, CSV, TXT, MD |

Each file can be up to 10 MB. Files that are too large or of another type are rejected right away, with a message such as "report.zip isn't a supported file type." If an upload fails, use **Retry upload** or **Remove attachment**.

Images appear as thumbnails. The agent reads the text of documents. Very long documents are cut off at 50,000 characters. Attachments are stored in your [media library](/media/library).

## Copy a message

Hover a message and open its **Message actions** menu. Choose **Copy text** to copy the message text. Reasoning, tool steps and files are not copied.

## Branch a conversation

Branching copies a chat up to a message, so you can try another direction without touching the original.

1. Hover the message you want to branch from.
2. Open **Message actions** and choose **Branch from here**.

RAGNA Studio opens a new chat with every message up to and including that one. It is named after the original with "(branch)" added. The original stays as it was. In the history, a branch shows "Forked from" and the original title.

## Chat history

Open the history with **Toggle chat history**. Chats are grouped by day, month or year. Use **Change grouping** to cycle through them. The panel shows "No chats yet" when you have none.

To rename a chat, hover it and choose **Rename chat**. A title is required. To delete a chat, choose **View all** on the **Chats** card of the [dashboard](/getting-started/dashboard-and-navigation). In the chat list, open the actions menu of a chat and choose **Delete**.

## Search chats

Use the search button next to the history toggle to open **Search chats**. Type at least 3 characters. Results update as you type.

Search looks at chat titles and message text. It matches parts of words, so "raph" finds "Raphaela". It ignores upper and lower case unless you turn on **Case sensitive**. Each result shows the chat with snippets of the matching text. Choose a result to open the chat. Use **Clear search** to start over.

Search covers the current workspace only.
