Knowledge is background material an agent should always have. Add it in the **Context** section of the agent. It works for facts like product details, style guides or price lists. For rules and behavior, use the instructions on the **Persona** section instead.

## Free text

Type or paste text into the **Background knowledge** field. The agent reads it in every chat.

The field works like the instructions in the **Persona** section: it is a formatted editor, and the text reaches the model exactly as written, including tags such as `<facts>`. Press the **Markdown** toggle to edit the stored markdown directly. See [Create an agent](/agents).

The field is limited to 30,000 characters. A counter in the bottom right corner shows the length, for example **12 / 30,000**. It turns red above the limit, and the agent cannot be saved until the text is shorter.

## Documents

Upload files under **Documents** in the **Context** section. RAGNA Studio extracts the text and adds it to the agent's knowledge.

The drop zone sits on top. Files can be dragged into it, or the zone can be clicked to browse. The supported types are PDF, DOCX, PPTX, XLSX, CSV, TXT and MD. Each file can be up to 10 MB. An agent holds up to 25 documents.

A table lists the documents with their **Status** and **Size**. The status is one of:

| Status      | Meaning                                                                               |
| ----------- | ------------------------------------------------------------------------------------- |
| **Pending** | RAGNA Studio is extracting the text. The list refreshes on its own.                   |
| **Ready**   | The agent can use the document.                                                       |
| **Failed**  | Extraction failed. Hover the badge to see why. Use **Retry extraction** to try again. |

The ⋮ menu of a row has **Rename document**, **Replace file**, **Retry extraction** and **Delete document**. Very long documents are cut off after 500,000 characters. The list then notes "Truncated: only the first part of this document was kept."

Only **Ready** documents count. The panel shows a summary of how the agent uses them.

## Small and large knowledge

RAGNA Studio decides how the agent reads its documents. Users don't configure it.

- **Up to 30,000 characters in total:** the full text of all ready documents goes into every chat. The agent sees everything at once.
- **Above 30,000 characters in total:** the agent gets only a list of document names and sizes. It uses a **Search Context** step to look up the passages it needs.

The switch is automatic. It happens when the documents grow past the limit, and it reverts if they shrink again. The free text in the **Background knowledge** field always goes into the chat in full.

What changes in large setups: in a chat the agent shows a **Search Context** tool call before it answers. Answers draw on the best matching passages, not on the whole document. If an answer misses a detail, ask the agent to search for it by name.
