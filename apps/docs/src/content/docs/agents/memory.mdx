Memory lets an agent keep durable facts between chats. It might remember the user's role, preferred tone or a project they work on. Each agent has its own memory. Agents do not share it.

## Turn memory on

Open the agent, go to the **Tools** tab and tick **Memory** ("Save and recall notes about you and your work across conversations"). Without this tool the agent neither saves nor reads memory.

## What the agent remembers

Memory is one text note per agent. The agent writes to it during a chat when it learns something worth keeping. It can add a new fact or change and remove one it saved earlier. It is told to skip trivial and short-lived details.

At the start of every chat, the agent reads the whole note. That is how it "remembers" the user in a new conversation. A chat shows a memory step when the agent updates its note.

## View and edit memory

1. Open the agent and choose the **Memory** tab.
2. Read or change the text in the **Memory** field.
3. Choose **Save**.

A user can correct a wrong fact, delete a line or add notes. Changes apply from the next chat on.

To clear memory, delete all the text and save. The agent then starts from a blank slate.

The tab shows "Save the agent first to view and edit its memory." for agents that are not saved yet.

## Good to know

- Memory is per agent, not per person. In a shared workspace, everyone who chats with the agent adds to and reads the same note. Keep personal details out of agents that others use.
- Memory differs from [Knowledge](/agents/knowledge). Knowledge is what a user gives the agent. Memory is what the agent writes down itself.
