---
title: linkedin-not-connected
description: A LinkedIn action was requested but the user has no LinkedIn connection.
---

`https://docs.ragna.io/errors/linkedin-not-connected`

## When it happens

A request needs the LinkedIn account of the user, for example to publish a social post. One of these applies:

- The user has not connected LinkedIn.
- The connection has LinkedIn posting turned off.
- The connection lacks the permission to post.
- The connection needs to be reconnected, or LinkedIn rejected the stored access. In the second case RAGNA Studio marks the connection as **Needs reconnect** and notifies the user. The post keeps its status.

## Response

| Member   | Value                  |
| -------- | ---------------------- |
| `status` | 400                    |
| `title`  | LinkedIn not connected |

No extension members.

```json
{
  "type": "https://docs.ragna.io/errors/linkedin-not-connected",
  "title": "LinkedIn not connected",
  "status": 400
}
```

## What the client can do

Send the user to the connection settings to connect LinkedIn, turn on LinkedIn posting, or reconnect. See [Connections](/integrations/connections). Then send the request again.
