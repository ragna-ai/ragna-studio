This runs the whole stack on localhost. It needs no proxy and no TLS. For a server setup, see [Self-hosting](/self-hosting).

## Before you start

You need Docker with Docker Compose v2, `curl` and `openssl`. You also need:

- One S3-compatible bucket setup, see [Storage](/self-hosting/storage).
- One OAuth app (Google or Microsoft), see [Configuration](/self-hosting/configuration#oauth). Use `http://localhost:3010/auth/callback/<provider>` as the redirect URI.
- At least one LLM API key.

## Install

```bash
curl -fsSL https://get.ragna.io | sh
```

<Steps>
  <Step title="Download">
    The script creates a `ragna-studio` folder in your current folder and downloads the compose files of the latest release into it. Set `RAGNA_DIR` to use another folder.
  </Step>
  <Step title="Configure">
    It creates `.env` with generated secrets and pins the release as `RAGNA_VERSION`. Then it asks for your domains (press Enter for localhost), OAuth app, storage and AI keys.
  </Step>
  <Step title="Start">
    It pulls the images of that release and starts the stack.
  </Step>
  <Step title="Open the app">
    Open [localhost:3000](http://localhost:3000). The API is on port 3010.
  </Step>
</Steps>

If a setting is missing, the script lists it and stops. Fill it in `ragna-studio/.env` and run the script again from the same folder. The [environment variables](/reference/environment-variables) reference lists every setting.

### Inspect first

To read the script before running it:

```bash
curl -fsSL https://get.ragna.io -o install.sh
less install.sh
sh install.sh
```

## Upgrade

Run it from the folder that contains `ragna-studio`:

```bash
curl -fsSL https://get.ragna.io | sh -s -- --upgrade
```

This moves `RAGNA_VERSION` to the latest release, refreshes the compose files, pulls the new images and restarts. Your `.env` stays as it is otherwise. Running the script without `--upgrade` keeps the pinned release.

## Stop

```bash
docker compose -p ragna_studio down
```

Your data stays in the Docker volumes.

<Aside type="caution" title="Localhost only">
  The app and the API listen on `127.0.0.1` only. To serve them to others, follow [Self-hosting](/self-hosting).
</Aside>
