The app has one navigation sidebar on the left. Everything opened in it belongs to the workspace selected at the top of the sidebar.

## The sidebar

The workspace switcher sits at the top. The selected workspace decides what every page shows. See [Workspaces](/workspaces).

Below it, the sidebar links to every area of the app:

| Item          | What it holds                                                                                         |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| **Mail**      | The user's connected mailbox. Shown only in the personal workspace. See [Email](/integrations/email). |
| **Dashboard** | The overview of the current workspace.                                                                |
| **Tasks**     | The task board. See [Tasks](/content/tasks).                                                          |
| **Workflows** | Automations built from agents. See [Workflows](/workflows).                                           |
| **Agents**    | The AI co-workers. See [Create an agent](/agents).                                                    |
| **Chat**      | Conversations with agents. See [Chat](/agents/chat).                                                  |
| **Datasets**  | Tables that users and agents share. See [Datasets](/content/datasets).                                |
| **Docs**      | Documents and folders. See [Documents](/content/documents).                                           |
| **Images**    | Image generation. See [Images](/media/images).                                                        |
| **Videos**    | Video generation. See [Videos](/media/videos).                                                        |
| **Social**    | Social media posts. See [Social posts](/integrations/social-posts).                                   |

The bell and the account menu sit at the bottom of the sidebar.

## The dashboard

The **Dashboard** greets the user and shows the latest activity of the current workspace in cards:

- **Tasks**: open tasks, grouped by status.
- **Documents**, **Workflows** and **Chats**: the most recently changed items.
- **Calendar**: tasks that are due this week. Page through the weeks with the arrows.
- **Agents**: the workspace's agents, one tile each.

Every card links to its full page with **View all**. An empty card offers a shortcut such as **New task** or **New chat**.

## Notifications

The bell shows a red dot when the user has unread notifications. A notification arrives when:

- a workflow run completes or fails,
- a task reminder is due,
- generated images or a generated video are ready, or failed.

Choose a notification to open what it is about. If it belongs to another workspace, the app switches there first. The panel can mark all as read, delete one notification, or clear all of them.

## The account menu

Choose the user's initials at the bottom of the sidebar to open the account menu:

- **Account** and **Settings** open the account page.
- **Organization** opens the organization settings. See [Organizations](/workspaces/organizations).
- **MCP** opens the MCP connector settings. It shows only when the connector is enabled. See [MCP connector](/integrations/mcp).
- **Sign out** ends the session.

The account page has these tabs:

| Tab                    | What it sets                                                 |
| ---------------------- | ------------------------------------------------------------ |
| **Profile**            | Name and avatar.                                             |
| **Connected accounts** | Connect or disconnect Google, Microsoft and LinkedIn.        |
| **Language**           | English or Deutsch.                                          |
| **Sidebar**            | **Show labels when collapsed** keeps the item names visible. |
| **Delete account**     | Deletes the account.                                         |
