RAGNA Studio has one navigation sidebar on the left. Everything opened in it belongs to the workspace selected at the top of the sidebar.

## The sidebar

The workspace switcher sits at the top. The selected workspace decides what every page shows. See [Workspaces](/workspaces).

Below it, the sidebar links to every area of RAGNA Studio:

| Item          | What it holds                                                                                         |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| **Mail**      | The user's connected mailbox. Shown only in the personal workspace. See [Email](/integrations/email). |
| **Dashboard** | The overview of the current workspace.                                                                |
| **Tasks**     | The task board. See [Tasks](/content/tasks).                                                          |
| **Workflows** | Automations built from agents. See [Workflows](/workflows).                                           |
| **Agents**    | The AI co-workers. See [Create an agent](/agents).                                                    |
| **Chat**      | Conversations with agents. See [Chat](/agents/chat).                                                  |
| **Datasets**  | Tables that users and agents share. See [Datasets](/content/datasets).                                |
| **Docs**      | Documents and folders. See [Documents](/content/documents).                                           |
| **Images**    | Image generation. See [Images](/media/images).                                                        |
| **Videos**    | Video generation. See [Videos](/media/videos).                                                        |
| **Social**    | Social media posts. See [Social posts](/integrations/social-posts).                                   |

The bell and the account menu sit at the bottom of the sidebar.

### Expand and collapse

The sidebar shows icons only by default. Choose the toggle at the bottom to expand it. Every item then shows its name, and so do the workspace switcher, the bell and the account menu. Choose the toggle again to collapse it. In the collapsed sidebar, hover an item to see its name.

RAGNA Studio remembers the choice after a reload.

## The dashboard

The **Dashboard** greets the user and shows the latest activity of the current workspace in cards:

- **Tasks**: open tasks, grouped by status.
- **Documents**, **Workflows** and **Chats**: the most recently changed items.
- **Calendar**: tasks that are due this week. Page through the weeks with the arrows.
- **Agents**: the workspace's agents, one tile each.

Every card links to its full page with **View all**. An empty card offers a shortcut such as **New task** or **New chat**.

## Notifications

The bell shows a red dot when the user has unread notifications. A notification arrives when:

- a workflow run completes or fails,
- a task reminder is due,
- generated images or a generated video are ready, or failed.

Choose a notification to open what it is about. If it belongs to another workspace, RAGNA Studio switches there first. The panel can mark all as read, delete one notification, or clear all of them.

## The account menu

Choose the user's initials at the bottom of the sidebar to open the account menu:

- **Settings** opens the settings area.
- **Sign out** ends the session.

## Settings

The settings area replaces the sidebar with its own navigation. Choose **Back to app** at the top to return to the page the user came from. When settings were opened directly, it goes to the dashboard.

Each section has its own address, so a reload or a shared link opens the same section.

| Group            | Section         | What it holds                                                                                                 |
| ---------------- | --------------- | ------------------------------------------------------------------------------------------------------------- |
| **Account**      | **Profile**     | Name and avatar. **Delete account** sits at the bottom.                                                       |
| **Account**      | **Language**    | English or Deutsch.                                                                                           |
| **Account**      | **Credits**     | The credit balance and what it was spent on.                                                                  |
| **Organization** | **General**     | Organization name, ownership transfer and deletion. See [Organizations](/workspaces/organizations).           |
| **Organization** | **Members**     | Members and invitations.                                                                                      |
| **Organization** | **Workspaces**  | Restricted workspaces. Shown to organization owners and admins only.                                          |
| **Organization** | **Usage**       | Credit usage by member. Shown to organization owners and admins only.                                         |
| **Email**        | **General**     | Mailbox, default draft agent and disconnect. See [Email](/integrations/email).                                |
| **Email**        | **Categories**  | Email categories.                                                                                             |
| **Email**        | **Senders**     | Auto-draft senders.                                                                                           |
| **Integrations** | **Connections** | Accounts RAGNA Studio acts with. See [Connections](/integrations/connections).                                |
| **Integrations** | **MCP**         | The MCP connector settings. Shown only when the connector is enabled. See [MCP connector](/integrations/mcp). |
