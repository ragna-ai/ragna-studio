All settings go into `.env`. The [installer](/self-hosting/install-options/one-line-setup) creates it from the release's `.env.example`.

The **Default** column shows the value RAGNA Studio uses when a variable is not set. `.env.example` sets its own values for some variables. Because the installer copies that file to `.env`, those values win. See [Values set by `.env.example`](#values-set-by-envexample). An empty default means the feature stays off until the variable is set.

## App and domains

| Variable                    | Default                     | Meaning                                                                                                                                                       |
| --------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`                  | `development`               | `development`, `production` or `test`                                                                                                                         |
| `RAGNA_VERSION`             | `latest`                    | Image tag for the RAGNA Studio containers, such as `X.Y.Z`, see [GitHub releases](https://github.com/ragna-ai/ragna-studio/releases). Read by Docker Compose. |
| `APP_URL`                   | `http://localhost:APP_PORT` | Public URL of the web app                                                                                                                                     |
| `APP_PORT`                  | `3000`                      | Port used to build the default `APP_URL`. It does not change the port the web app listens on.                                                                 |
| `API_PORT`                  | `3010`                      | Port the API listens on. The compose files and the health check assume `3010`.                                                                                |
| `API_BASE_URL`              | `APP_URL` + `/`             | Public URL of the API                                                                                                                                         |
| `NUXT_PUBLIC_API_BASE_URL`  |                             | Public API URL for the browser. Must be **https** in production.                                                                                              |
| `TRUSTED_ORIGINS`           | `http://localhost:3000`     | Comma-separated list of allowed origins                                                                                                                       |
| `COOKIE_DOMAIN`             |                             | Parent domain, such as `.example.com`. Needed when app and API are on separate hosts.                                                                         |
| `NUXT_PUBLIC_I18N_BASE_URL` | `https://ragna.io`          | Base URL for language links                                                                                                                                   |
| `LOG_LEVEL`                 | `info`                      | `trace`, `normal`, `debug`, `info`, `warn` or `error`                                                                                                         |
| `AI_SDK_LOG_WARNINGS`       | `true`                      | Set to `false` to silence AI SDK warnings                                                                                                                     |

See [Configuration](/self-hosting/configuration#domains).

## Values set by `.env.example`

These variables have a different value in `.env.example` than in the code. The installer copies them into `.env`.

| Variable              | Default         | `.env.example`          | Note                                                            |
| --------------------- | --------------- | ----------------------- | --------------------------------------------------------------- |
| `API_BASE_URL`        | `APP_URL` + `/` | `http://localhost:3010` | The installer sets it to the API URL entered.                   |
| `LOG_LEVEL`           | `info`          | `debug`                 |                                                                 |
| `AI_SDK_LOG_WARNINGS` | `true`          | `false`                 |                                                                 |
| `MAIL_FROM`           |                 | `noreply@example.com`   |                                                                 |
| `SMTP_PORT`           | `587`           | `2525`                  | Port of a local mail catcher.                                   |
| `DB_PORT`             | `5432`          | `5437`                  | The self-host compose override sets `5432` for the containers.  |
| `DB_PASSWORD`         | `mypassword`    | `changeme`              | The installer generates a random value.                         |
| `REDIS_HOST`          |                 | `localhost`             | The self-host compose override sets `redis` for the containers. |
| `REDIS_PORT`          | `6379`          | `6381`                  | The self-host compose override sets `6379` for the containers.  |
| `REDIS_PASSWORD`      |                 | `changeme`              | The installer generates a random value.                         |

## Storage

| Variable                   | Default | Meaning                                           |
| -------------------------- | ------- | ------------------------------------------------- |
| `S3_ENDPOINT`              |         | Endpoint of the S3 provider                       |
| `S3_REGION`                | `auto`  | Bucket region. R2 wants `auto`.                   |
| `S3_ACCESS_KEY_ID`         |         | Access key                                        |
| `S3_SECRET_ACCESS_KEY`     |         | Secret key                                        |
| `S3_IMAGES_BUCKET_NAME`    |         | Public-read bucket for images and generated media |
| `S3_DOCUMENTS_BUCKET_NAME` |         | Private bucket for documents                      |
| `MEDIA_URL`                |         | Public base URL of the images bucket              |
| `NUXT_PUBLIC_MEDIA_URL`    |         | Same value as `MEDIA_URL`                         |

Setting `S3_ENDPOINT` requires `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_IMAGES_BUCKET_NAME`, `S3_DOCUMENTS_BUCKET_NAME` and `MEDIA_URL`. The installer refuses to start until all of them are set. `S3_REGION` stays optional.

See [Storage](/self-hosting/storage).

## AI providers

Set at least one chat provider. Each `*_API_BASE_URL` is optional and overrides the provider's default endpoint.

| Variable                                                                                                                                      | Meaning                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_API_BASE_URL`                                                                                                 | Anthropic                                    |
| `OPENAI_API_KEY`, `OPENAI_API_BASE_URL`                                                                                                       | OpenAI, also used for embeddings             |
| `MISTRAL_API_KEY`, `MISTRAL_API_BASE_URL`                                                                                                     | Mistral                                      |
| `GOOGLE_GENAI_API_KEY`, `GOOGLE_GENAI_API_BASE_URL`                                                                                           | Google GenAI                                 |
| `GOOGLE_VERTEX_PROJECT_ID`, `GOOGLE_VERTEX_LOCATION`, `GOOGLE_VERTEX_CLIENT_EMAIL`, `GOOGLE_VERTEX_PRIVATE_KEY`, `GOOGLE_VERTEX_API_BASE_URL` | Google Vertex, for Imagen and Veo            |
| `BFL_API_KEY`, `BFL_API_BASE_URL`                                                                                                             | Black Forest Labs, for FLUX images and video |
| `LMSTUDIO_API_KEY`, `LMSTUDIO_API_BASE_URL`                                                                                                   | LM Studio, for local models                  |

| Variable                    | Default            | Meaning                       |
| --------------------------- | ------------------ | ----------------------------- |
| `CHAT_TITLE_MODEL_PROVIDER` | `anthropic`        | Provider that names new chats |
| `CHAT_TITLE_MODEL`          | `claude-haiku-4-5` | Model that names new chats    |

## Web search and browser

| Variable                     | Default                            | Meaning                                                                                                   |
| ---------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `SERP_API_KEY`               |                                    | SerpAPI key for web search                                                                                |
| `WEBBROWSER_PORT`            | `3011`                             | Port of the headless browser service                                                                      |

| `BROWSER_IDLE_CLOSE_AFTER`   | `5m`                               | Close the idle browser after this long without scrapes. Units: `m`, `h`, `d`, `w`. `0m` keeps it running. |
