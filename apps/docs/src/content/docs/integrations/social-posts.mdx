RAGNA Studio can prepare social posts and publish them to the user's profile. LinkedIn is the supported network. A user writes a draft, or an agent writes it. Nothing goes live until the user chooses **Publish**.

Posts belong to the workspace they are created in. Publishing is manual. There is no scheduling.

<Aside type="note">
  On a self-hosted instance, publishing needs a LinkedIn app. See [Optional
  providers](/self-hosting/optional-providers) and [Environment
  variables](/reference/environment-variables).
</Aside>

## Connect LinkedIn

Drafts can be written without a connection. To publish, connect a LinkedIn account first. Signing in with LinkedIn does not grant posting rights.

1. Open the user menu, choose **Settings**, then **Connections**.
2. Next to **LinkedIn posting**, choose **Connect**.
3. Sign in at LinkedIn and approve the access.

The post page offers the same step: without a connection it shows **LinkedIn not connected** with a **Connect LinkedIn** button, and the post stays a draft. The LinkedIn account does not need the sign-in email. Choose **Remove** under **Connections** to remove the link, see [Connections](/integrations/connections).

LinkedIn access expires after about 60 days. RAGNA cannot renew it on its own. The connection then reads **Needs reconnect**. Choose **Reconnect** and retry.

## Write a post

Open **Social** in the navigation. The page **Social posts** lists the posts with their status.

1. Choose **New post**. RAGNA creates an empty draft and opens the editor.
2. Write in the text field **What do you want to share?**. A post can have up to 3,000 characters.
3. Choose **Save**. The toast **Draft saved.** confirms it.

Open a post from the list to edit it. A post can be deleted from the list after confirming.

### Add images

In the editor, choose **Attach image**.

- A post can have up to 9 images.
- JPEG, PNG and GIF are supported.
- Each image must be 10 MB or smaller.

Use **Edit alt text** to describe an image for screen readers. Use **Remove image** to take one off the post.

## Let an agent draft posts

Turn on the **LinkedIn Draft** tool for an agent. See [Agent tools](/agents/tools). Then ask the agent in a chat to write a post. It saves a draft and never publishes. When the agent generated images earlier in the same chat, it can attach up to 9 of them to the draft. Ask it again to revise the same draft.

Workflows can create drafts too. See [Workflows](/workflows).

Agent drafts show up in the **Social posts** list like any other. Review and edit them before publishing.

## Publish

1. Open the draft.
2. Choose **Publish**.

RAGNA sends the text and images to LinkedIn. A post cannot be empty. When it works, the status turns to **Published**, RAGNA Studio shows **Post published.**, and **View on LinkedIn** opens the live post. The post shows the LinkedIn account that published it. Publishing can take a moment when the post has several images.

## Post statuses

| Status        | Meaning                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| **Draft**     | Saved in RAGNA, not on LinkedIn. It can be edited and published.                                          |
| **Published** | Live on LinkedIn.                                                                                         |
| **Failed**    | LinkedIn rejected the post, or the LinkedIn access expired. Fix the cause, then choose **Publish** again. |
