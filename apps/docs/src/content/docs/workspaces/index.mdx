A workspace holds agents, chats, documents, datasets, tasks, workflows and media. Every item lives in exactly one workspace. The switcher at the top of the sidebar changes the active workspace.

## Workspace types

Every workspace has a type. The creator chooses it when creating the workspace.

| Type             | Who can open it                                                                                                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Personal**     | Only its owner. Every user has one named "Private". New users get it at sign-up. Existing users got it at the upgrade. |
| **Organization** | Every user in the organization.                                                                                        |
| **Restricted**   | Its workspace members, plus organization owners and admins.                                                            |

The switcher groups workspaces by type. Restricted workspaces show a lock icon. Organization owners and admins can open every restricted workspace, but the switcher lists only the ones they are a member of. See [Organizations](/workspaces/organizations) for how they find the others.

## Create a workspace

Every organization member can create workspaces.

1. Open the switcher and choose **Manage workspaces**.
2. Choose **New workspace**.
3. Enter a name and pick the **Visibility**: **Restricted** or **Organization**. Restricted is preselected. A user cannot create another personal workspace.
4. For a restricted workspace, pick the organization members who should get access under **Workspace members**. They join as editors.
5. Choose **Create workspace**.

The creator becomes the workspace manager of every workspace they create.

If a user has no workspace yet, RAGNA Studio shows a **Create a workspace** button instead of its pages.

## Rename and delete a workspace

In **Manage workspaces**, workspace managers see a rename (pencil) icon and a delete (trash) icon next to each workspace.

Deleting a workspace deletes everything in it: agents, chats, documents, datasets, tasks, workflows and media. It cannot be undone. A personal workspace cannot be deleted.

## Switch workspaces

Open the switcher at the top of the sidebar and pick a workspace. The pages show only the items of the active workspace.

## Scheduled workflows

A scheduled workflow pauses if its author can no longer open the workspace. See [Triggers](/workflows/triggers).
