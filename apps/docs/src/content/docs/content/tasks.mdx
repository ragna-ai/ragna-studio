Tasks give each workspace one kanban board. Users and agents create tasks, move them between columns and attach files. The board belongs to the workspace, so every user with access to the workspace sees the same tasks.

Open **Tasks** in the sidebar. Each task gets an ID like `TSK-12`, numbered per workspace.

## Board and list

Switch between **Board** and **List** in the toolbar. RAGNA Studio remembers the choice.

- **Board** shows one column per status. Drag a card to another column or to a new position.
- **List** shows a table grouped by status.

Filter by **Status**, **Priority** and **Label**. Both views share the filters.

Choose **New task** to create a task in **Backlog**. To create it in a given status, choose **+** in that column's header or in that group's row of the list. Press **Cmd+Enter** (**Ctrl+Enter** on Windows) or choose **Create task**. Turn on **Create more** to add several tasks in a row: the window stays open and keeps the properties.

## Status columns

The columns are **Backlog**, **Todo**, **In Progress**, **In Review**, **Done** and **Canceled**. They are fixed and cannot be added or renamed.

## Task details

Click a card to open the task page. The description uses the same editor as [Documents](/content/documents#the-editor) and saves on its own. The side panel holds the properties, such as priority, due date and labels.

- **Assignee:** assign the task to one of the workspace's agents. Assignment is a label only. The agent does not start working on its own.
- **Remind me:** see [Reminders](#reminders).

Use **Delete task** to remove a task. Its subtasks stay and become top-level tasks.

## Labels

Labels belong to the workspace. Choose **Labels** on the tasks page, or **Manage labels** in the labels picker of a new task, to create, rename, recolour and delete them. Deleting a label removes it from every task. It does not delete any task. Agents can attach existing labels but cannot create new ones.

## Subtasks

Add subtasks under **Subtasks** on the task page. Subtasks go one level deep: a subtask cannot have subtasks of its own. Open a subtask and use **Back to parent task** to return. The parent card shows how many subtasks are done.

## Reminders

Set a due date, then choose a value under **Remind me**: from **On due date** up to **1 week before**, or **Custom** for a number of days. Without a due date the option is disabled. RAGNA Studio sends one in-app notification, titled **Task reminder**, to the bell. The reminder moves with the due date. If the due date changes, the reminder is armed again. A task in **Done** or **Canceled** sends no reminder.

The notification goes to the organization owners. See [Organizations](/workspaces/organizations).

## Attachments

Choose **Add files** under **Attachments** on the task page, or drop files onto it. Subtasks can have attachments too.

| Limit            | Value                                                          |
| ---------------- | -------------------------------------------------------------- |
| File size        | 10 MB per file.                                                |
| Files per upload | 5.                                                             |
| Allowed types    | PNG, JPEG, WebP, PDF, DOCX, PPTX, XLSX, CSV, TXT and Markdown. |

RAGNA Studio checks the content of each file, not just its name. Agents do not read attachments. Attachments also appear in the [Media library](/media/library).

## Agents and tasks

Turn on the **Tasks** tool in an agent. It can then list, read, create, update and move tasks in the workspace. It can also assign agents and attach existing labels. Agents cannot delete tasks. Use **Canceled** to drop work. See [Agent tools](/agents/tools).

Changes made by an agent show up after the page reloads.
