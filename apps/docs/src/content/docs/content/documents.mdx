Documents are rich text notes that live in a workspace. Every user with access to the workspace can open them. Agents can read and edit them too.

Open **Documents** in the sidebar. Choose **New document**, enter a title (or keep **Untitled document**) and optionally pick a folder. See [Folders](#folders).

## The editor

The editor saves changes on its own. The status next to the title reads **Saving...** and then **Saved**. Click the title (**Rename document**) to change it.

There is no fixed toolbar. Controls appear next to the text instead.

### Format selected text

Selecting text shows a menu above the selection. It has:

- a **Block type** dropdown: **Text** and **Heading 1** to **Heading 4**,
- **Bold**, **Italic**, **Strikethrough** and **Inline code**,
- **Bulleted list**, **Numbered list**, **Task list**, **Quote** and **Code block** buttons,
- **Link**. Enter the address and choose **Apply**. Choose **Remove** to take a link off.

The dropdown shows the type of the current block. It reads **Mixed** when the selection spans blocks of different types. Choosing a type converts every selected block.

The list, quote and code block buttons show when they are active. Choosing an active list, quote or code block button turns the block back into text.

The menu does not appear on an image. Inside a code block it appears, but the formatting and link buttons are disabled.

### Tables

When the cursor is in a table, a table menu appears. It can add a row above or below, add a column before or after, and delete a row, a column or the whole table. A new table has three rows, three columns and a header row.

### Insert blocks with /

Type `/` on an empty line or after a space to open the command menu. Keep typing to narrow the list. Use the arrow keys and **Enter** to pick an item. Press **Esc** to close the menu and keep the `/` as text.

The menu offers:

- **Text**, **Heading 1** to **Heading 4**,
- **Bulleted list**, **Numbered list** and **Task list**,
- **Quote** and **Code block**,
- **Divider** and **Table**,
- **Image** (by URL).

Each item shows its Markdown shortcut. The menu does not open inside a code block or inline code.

### Markdown shortcuts

Markdown typed at the start of a line converts as the user types:

| Type          | Result         |
| ------------- | -------------- |
| `#` to `####` | Heading 1 to 4 |
| `-`           | Bulleted list  |
| `1.`          | Numbered list  |
| `[ ]`         | Task list      |
| `>`           | Quote          |
| ` ``` `       | Code block     |
| `---`         | Divider        |

Type a space after `#`, `-`, `1.`, `[ ]` and `>`.

### Keyboard shortcuts

Use ⌘ on macOS and Ctrl on Windows and Linux.

| Action         | Shortcut                          |
| -------------- | --------------------------------- |
| Bold           | ⌘ B / Ctrl+B                      |
| Italic         | ⌘ I / Ctrl+I                      |
| Strikethrough  | ⌘ Shift S / Ctrl+Shift+S          |
| Inline code    | ⌘ E / Ctrl+E                      |
| Link           | ⌘ K / Ctrl+K                      |
| Text           | ⌘ Option 0 / Ctrl+Alt+0           |
| Heading 1 to 4 | ⌘ Option 1 to 4 / Ctrl+Alt+1 to 4 |
| Numbered list  | ⌘ Shift 7 / Ctrl+Shift+7          |
| Bulleted list  | ⌘ Shift 8 / Ctrl+Shift+8          |
| Task list      | ⌘ Shift 9 / Ctrl+Shift+9          |
| Quote          | ⌘ Shift B / Ctrl+Shift+B          |
| Code block     | ⌘ Option C / Ctrl+Alt+C           |
| Undo           | ⌘ Z / Ctrl+Z                      |
| Redo           | ⌘ Shift Z / Ctrl+Shift+Z          |

Documents are stored as Markdown. Formatting that Markdown cannot express is not supported. This includes underline, highlight and text alignment.

<Aside type="note">
  Only one user should edit a document at a time. There is no live collaboration. The last save
  wins. If an agent edits a document that is open, reload the page to see the change.
</Aside>

## Folders

The documents page works like a file browser. The top level lists all folders first. Below them are the documents that are in no folder. Each folder row shows how many documents it holds.

Folders are flat. They cannot contain other folders.

### Open a folder

Click a folder to open it. The page then lists only that folder's documents. A breadcrumb (**Documents** > folder name) shows where you are. Choose **Documents** in the breadcrumb, or use the browser's back button, to return to the top level.

The address of an open folder can be shared. Other members of the workspace who open it see the same folder. If the folder was deleted, the page reads **Folder not found** and links back to the top level.

### Create a folder

Choose **New folder** in the page header, enter a name and choose **Create**. A name has 1 to 255 characters. Two folders can share a name.

### Folder actions

Open the actions menu on a folder row:

- **Rename folder** changes the name in the list and in the breadcrumb.
- **Delete folder** asks for confirmation. Deleting a folder does not delete its documents. They move to the top level.

### Document actions

Open the actions menu on a document row:

- **Move to folder** lists all folders and **No folder**. The document leaves the current list and the folder counts update.
- **Delete document** removes the document.

The list also shows the **Author** of each document: the user or agent that created it.

### New documents

**New document** inside an open folder files the document in that folder. At the top level the document is in no folder. You can still pick another folder in the dialog.

## Sharing with agents

Turn on the **Documents** tool in an agent. The agent can then list, read, create and edit documents in its workspace. Agents cannot delete documents or manage folders. Documents an agent creates show the agent as author. See [Agent tools](/agents/tools).

Documents are not added to a chat automatically. The agent reads them with its tools when it needs them. To give an agent fixed background material, use [Knowledge](/agents/knowledge) instead.

## Export

Choose **Export** in the editor and pick **Markdown**, **Text**, **PDF** or **Word**. The file downloads at once.

## Delete a document

Choose **Delete document** in the list. This cannot be undone.
