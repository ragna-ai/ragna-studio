Documents are rich text notes that live in a workspace. Everyone with access to the workspace can open them. Agents can read and edit them too.

Open **Documents** in the sidebar. Choose **New document**, enter a title (or keep **Untitled document**) and optionally pick a folder.

## The editor

The editor saves your changes on its own. The status next to the title reads **Saving...** and then **Saved**. Click the title (**Rename document**) to change it.

The toolbar offers:

- headings, **Bold**, **Italic**, **Underline**, **Strikethrough** and **Highlight**,
- text alignment, lists and a **Task list**,
- **Code block**, **Link** and **Image** (by URL),
- tables with row and column actions,
- **Undo** and **Redo**.

A word count shows at the bottom. Documents are stored as Markdown. Formatting that Markdown cannot express is not supported.

<Aside type="note">
  Only one person should edit a document at a time. There is no live collaboration. The last save
  wins. If an agent edits a document you have open, reload the page to see the change.
</Aside>

## Folders

Choose **Folders** on the documents page to create, rename and delete folders. Folders are flat. They cannot contain other folders.

Move a document to a folder from the list. The list also shows the **Author** of each document: the person or agent that created it.

Deleting a folder does not delete its documents. They move to the root level (**No folder**).

## Sharing with agents

Turn on the **Documents** tool in an agent. The agent can then list, read, create and edit documents in its workspace. Agents cannot delete documents or manage folders. Documents an agent creates show the agent as author. See [Agent tools](/agents/tools).

Documents are not added to a chat automatically. The agent reads them with its tools when it needs them. To give an agent fixed background material, use [Knowledge](/agents/knowledge) instead.

## Export

Choose **Export** in the editor and pick **Markdown**, **Text**, **PDF** or **Word**. The file downloads at once.

## Delete a document

Choose **Delete document** in the list. This cannot be undone.
